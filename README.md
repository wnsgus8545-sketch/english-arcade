# 🎮 English Arcade — 우리 반 영어 오락실

학생은 **반 코드 · 번호 · 닉네임** 만 넣고 들어와 영어 미니게임 7개를 합니다.
점수·코인·아이템은 Firebase 에 저장되고, 순위는 실시간으로 바뀝니다.

| 화면 | 주소 |
|---|---|
| 학생 | `index.html` (선생님 화면에서 `?code=반코드` 가 붙은 링크를 복사해 나눠 주세요) |
| 선생님 | `teacher.html` |

## 게임 7개

| 게임 | 내용 | 쓰기 |
|---|---|---|
| 🌧️ 단어 비 | 떨어지는 뜻을 보고 영어로 쳐서 터뜨리기 | 전부 쓰기 · **점수 ×2** |
| 🧠 뜻 맞히기 퀴즈 | 4지선다 | 3문제마다 ✍️ 쓰기 찬스 |
| 🔨 단어 두더지 (NEW) | 뜻에 맞는 영어 두더지 잡기 | 🌟황금 두더지 = 쓰기 찬스 |
| 🃏 카드 짝맞추기 | 영어-뜻 카드 짝 찾기 | 판을 깨면 🎁 보너스 쓰기 2문제 |
| 🧩 문장 퍼즐 | 예문 단어를 순서대로 놓기 | 2문제마다 빈칸 쓰기 |
| 🔐 금고 깨기 (NEW) | 알파벳을 골라 철자 맞히기 | 철자 |
| ⚡ 스피드 O/X (NEW) | 단어-뜻이 맞는지 빠르게 고르기 | — |

- 쓰기 문제는 **어느 게임에서 나와도 점수 2배**. 쓰는 동안은 시간이 절반 속도로 흐릅니다.
- 5콤보마다 배수가 0.5씩 오릅니다 (최대 ×3).
- 코인은 게임 점수 5점마다 1개. 🛒상점에서 아이템을 삽니다.

## 아이템이 빨라진 이유

예전(Apps Script)에는 아이템을 누를 때마다 **서버에 갔다 와야** 적용됐습니다(1~3초).
지금은 **누르는 순간 화면에서 먼저 적용**하고, 저장은 0.35초 모아서 뒤에서 보냅니다.

## 처음 한 번만: 설치 순서

### 1. Firebase 프로젝트 만들기 (약 10분)

1. [Firebase 콘솔](https://console.firebase.google.com) 에 구글 계정으로 들어가 **[프로젝트 추가]**
   - 이름: 아무거나 (예: `english-arcade`) · 구글 애널리틱스는 **끄기**
2. 왼쪽 메뉴 **빌드 → Authentication → [시작하기]**
   - **로그인 방법** 탭에서 **익명** → 사용 설정 → 저장 (학생용)
   - **Google** → 사용 설정 → 지원 이메일 고르기 → 저장 (선생님용)
3. 왼쪽 메뉴 **빌드 → Realtime Database → [데이터베이스 만들기]**
   - 위치: **싱가포르(asia-southeast1)** · **잠금 모드로 시작**
   - 만들어지면 **규칙** 탭을 누르고, 안에 있는 글을 전부 지운 뒤
     이 폴더의 `database.rules.json` 내용을 통째로 붙여넣고 **[게시]**
4. 왼쪽 위 ⚙️ → **프로젝트 설정** → 아래쪽 **내 앱** 에서 웹 아이콘 `</>` 누르기
   - 앱 닉네임 아무거나 · «Firebase 호스팅» 체크는 **안 함** → [앱 등록]
   - 나오는 `firebaseConfig = { ... }` 안의 값들을 `js/firebase-config.js` 에 붙여넣고 **저장(Ctrl+S)**
   - `databaseURL` 이 비어 있으면 Realtime Database 화면 맨 위의 `https://....firebasedatabase.app` 주소를 넣어 주세요

> `firebase-config.js` 값은 비밀번호가 아니라 «주소» 라서 GitHub 에 올라가도 됩니다.
> 누가 무엇을 쓸 수 있는지는 3번의 규칙이 막아 줍니다.

### 2. GitHub 에 올려서 주소 만들기 (약 5분)

1. [GitHub](https://github.com) 로그인 → 오른쪽 위 **＋ → New repository**
   - 이름: `english-arcade` · **Public** → [Create repository]
2. 새 저장소 화면에서 **uploading an existing file** 글자를 누르고,
   이 폴더 안의 파일·폴더(`index.html`, `teacher.html`, `css`, `js` …)를 **전부 끌어다 놓기** → [Commit changes]
3. 저장소 **Settings → Pages**
   - Source: **Deploy from a branch** · Branch: **main** / **(root)** → [Save]
   - 1~2분 뒤 위쪽에 `https://아이디.github.io/english-arcade/` 주소가 뜹니다
4. 다시 Firebase 콘솔 → **Authentication → 설정 → 승인된 도메인 → [도메인 추가]**
   - `아이디.github.io` 를 넣고 추가 (이걸 안 하면 선생님 구글 로그인이 막힙니다)

### 3. 수업에서 쓰기

1. `https://아이디.github.io/english-arcade/teacher.html` → 구글 로그인
2. **＋ 새 반 만들기** → 반 코드가 생깁니다
3. **단어 목록** 에 `영어 | 뜻 | 예문` 을 한 줄씩 (시트에서 복사해 붙여넣어도 됨) → 💾 저장
4. **학생 입장 안내** 의 주소를 복사해 학생들에게 나눠 줍니다
5. 📺 **전체 화면 순위** 를 TV 에 띄우고, 마무리 5분엔 ⚡ **2배 타임**

## 고친 뒤 다시 올리기

GitHub 저장소에서 바꾼 파일을 다시 끌어다 놓고 [Commit changes] 하면 1~2분 뒤 반영됩니다.
학생 화면이 안 바뀌면 **Ctrl+F5** (강력 새로고침).

## 체험 모드

`js/firebase-config.js` 가 비어 있으면 **체험 모드** 로 돌아갑니다. 이 컴퓨터 브라우저에만 저장되고, 반 코드는 `DEMO` 입니다.
같은 컴퓨터에서 `teacher.html` 을 다른 탭으로 열면 순위·2배 타임이 실시간으로 움직이는 것까지 시험해 볼 수 있습니다.
